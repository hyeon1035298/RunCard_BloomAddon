# 작업 카드 (Bloom 애드온)

Claude Code 세션이 일하는 동안 화면 한쪽에 세션마다 작은 알약이 하나씩 뜹니다. 알약에는 지금 하는
일과 걸린 시간이 보이고, 포인터를 올리면 그 자리에서 카드로 펼쳐집니다. 카드에는 모델, 지금 몇
번째 단계인지, 단계 막대, 최근 다섯 단계와 각 단계에 걸린 시간이 나옵니다. 디자인은
@eliakuratli가 공개한 실행 상태 카드 시안을 따랐고, 색과 글꼴은 Bloom 디자인 시스템입니다.

- 승인 요청과 Claude의 질문이 오면 카드가 저절로 펼쳐지고, 카드에서 바로 허용·거절하거나 답을 골라
  보낼 수 있습니다. "터미널에서"를 누르면 Bloom이 그 세션 창을 앞으로 가져옵니다. 이 기능은 Bloom이
  이미 쓰는 승인 훅을 그대로 거치므로 Claude Code에 따로 설치하는 것이 없습니다.
- 일이 끝나면 "13초 만에 완료 · 파일 6개 바뀜"으로 잠시 남았다가 사라집니다. 오른쪽 클릭하면 바로
  닫힙니다.
- 모니터(주 모니터 또는 Windows 디스플레이 번호)와 여덟 자리(네 모서리, 위·아래 가운데, 왼쪽·오른쪽
  가운데) 중 하나를 고릅니다. 세션이 여럿이면 들어온 순서대로 그 자리에서 쌓이고, 펼치거나 접을 때
  나머지가 부드럽게 자리를 옮깁니다. 가운데 자리는 위아래로 고르게 퍼집니다.
- 애드온이 Bloom에 연결되어 있는 동안 Bloom은 Claude Code의 진행 중·작업 완료·승인 대기 알림을
  띄우지 않습니다. Codex 알림과 사용량 알림은 그대로입니다. 애드온을 끄면 Bloom 알림이 돌아옵니다.
- Claude Code가 쓰는 기록(`%USERPROFILE%\.claude\projects`, 다른 설정 폴더와 Bloom 계정 폴더도)만
  읽고, 토큰을 쓰지 않습니다. 화면에는 도구 이름, 파일 경로의 마지막 부분, 주소의 호스트, 모델이 쓴
  짧은 설명만 보이고 메시지 내용은 보이지 않습니다. 아무 데도 보내지 않습니다(Bloom과는 이 PC
  안에서만 이야기합니다).
- 전체 화면 앱이 앞에 있으면 숨고, 그동안 온 승인 요청은 Bloom 카드로 갑니다.

## 설정 (Bloom에서)

| | |
|---|---|
| 모니터 | 주 모니터, 1–4번 |
| 자리 | 여덟 곳 (오른쪽 위) |
| 늘어놓기 | 세로, 가로 |
| 가장자리 여백 | 0–200 (16) |
| 크기 | 80–150% (100%) |
| 펼치기 | 포인터를 올리면, 늘 펼침 |
| 완료 카드 남기기 | 0–600초 (20) |
| 카드에서 승인·질문 답하기 | 켬 |
| 하위 작업 보기 | 끔 |
| 테마 | Windows 작업표시줄 테마, 다크, 라이트 |
| 알약 길이 | 같은 길이, 내용에 맞춤 |

승인과 질문을 카드에서 받으려면 작업 카드 연결이 들어간 Bloom(1.4.3 다음 버전)이 필요합니다. 그 전
Bloom에서도 카드는 뜨고, 승인은 Bloom 카드로 옵니다.

## 빌드

`bash build.sh` (PillTaskbar_BloomAddon의 애드온 도구와 SessionIsland_BloomAddon의 기록 읽기 코드가
옆 폴더에 있거나 `PILL_ROOT`, `SI_ROOT`). `build/addon`에 `RunCardHost.exe`, `RunCardRuntime.dll`,
`RunCard.dll`, `addon.json`, `settings.schema.json`, 고지 파일이 나옵니다.

시험: `bash tools/build-card-host.sh`(카드 그림을 PNG로, 모델 검사), `bash tools/build-run-host.sh`
(런타임과 애드온을 explorer 밖에서 실행하고, Bloom 대역을 세워 승인·질문 응답을 확인).
